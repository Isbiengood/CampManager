# Application mobile web

Cette partie contient l'interface mobile utilisée par le personnel de ménage et les gouvernantes.

## Fonctions validées

- première activation ;
- connexion PIN ;
- oubli / renouvellement d'accès ;
- verrouillage après erreurs ;
- réactivation ;
- liste des tâches ;
- À faire → À vérifier ;
- À vérifier → Prêt ;
- fonctionnement multi-établissement.

## Configuration

Le navigateur peut contenir :

- l'URL Supabase ;
- une clé Supabase publishable.

Il ne doit jamais contenir de clé serveur ni de jeton privé Apps Script.

## Publication

La version actuellement testée reste séparée de l'ancien site stable tant que le nouveau dépôt n'a pas terminé ses contrôles.
