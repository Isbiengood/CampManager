Installation CampManager

Nom de votre établissement

Camping, hôtel, résidence ou autre établissement : saisissez simplement son nom pour commencer.

Vous réutiliserez ce nom au moment d’activer votre copie CampManager.
✓ Votre code d’activation est prêt
Il est à usage unique et valable 7 jours. Conservez-le jusqu’à la fin de l’installation.
—

Créer votre copie

1
Cliquez une première fois sur le bouton bleu pour copier le code. Le bouton confirmera « Code copié ✓ » avant de vous proposer d’ouvrir le MASTER.
2
Cliquez une deuxième fois sur le bouton devenu « Ouvrir le MASTER et créer ma copie ».
3
Dans la copie, choisissez ⚙️ Établissement / installation → 🚀 Installer un nouvel établissement, saisissez le nom puis collez le code avec Ctrl+V.
Un compte Google est nécessaire pour enregistrer la copie du fichier.
