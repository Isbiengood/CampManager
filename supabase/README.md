# Supabase

Ce dossier contiendra :

- `migrations/` — schéma et RPC CampManager ;
- `functions/campmanager-v4-bridge/` — pont sécurisé Apps Script → Supabase ;
- `scripts/` — création de code d'installation et smoke tests ;
- `config.toml` — configuration locale Supabase CLI.

Aucune donnée réelle ni aucun secret ne doit être committé.
