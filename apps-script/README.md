# Apps Script

Ce dossier accueillera l'export propre du projet Apps Script lié au **MASTER Open Source**.

## Référence actuelle

Version métier validée : **V4.2.7 — départs anticipés protégés**.

## Règles

- le MASTER reste la source de référence ;
- aucun secret ne doit être codé dans les fichiers ;
- le jeton d'établissement appartient aux Propriétés du script ;
- les correctifs sont testés d'abord dans l'environnement de test indépendant ;
- ne pas recopier des fichiers depuis l'ancien environnement de production sans comparaison.

## Compatibilité

Certains noms de fonctions internes peuvent encore porter des noms historiques pour éviter une régression. Ils seront nettoyés progressivement avant la publication publique, avec tests de non-régression.
